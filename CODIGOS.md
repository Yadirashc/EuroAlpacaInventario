# Material y modelo

Ejemplo: **ACSU38** = AC (Baby Alpaca + algodón) + SU38 (modelo Suyay).

Solo el material y el modelo determinan el código. Colores, tallas y porcentajes no lo cambian. Se unifican diferencias de mayúsculas, espacios y acentos. Las variantes conservan sus cantidades y precios.
